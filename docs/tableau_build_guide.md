# Credit Portfolio Risk & Operations Control Tower — Tableau Build Guide

## Prerequisites
- Tableau Public Desktop (free) or Tableau Desktop (14-day trial)
- loans_clean.csv (generated by prep.py)
- dq_summary.csv (generated by prep.py)

## Step 1: Data Connection
1. Open Tableau Desktop/Public
2. Connect > Text File > select `loans_clean.csv`
3. Go to Data Source tab:
   - Change `issue_date` to Date type
   - Change `last_pymnt_date` to Date type
   - Right-click `addr_state` > Geographic Role > State/Province
   - Click "Extract" radio button (not Live)
4. Click "Sheet 1" to go to workspace

## Step 2: Data Source Organisation
1. Create folders in the Data pane:
   - **Keys**: id
   - **Dates**: issue_date, last_pymnt_date
   - **Loan Terms**: loan_amnt, funded_amnt, term_months, int_rate, installment
   - **Borrower**: grade, sub_grade, home_ownership, annual_inc, verification_status, purpose, addr_state, dti, fico, delinq_2yrs, open_acc, revol_util, application_type
   - **Balances**: out_prncp, total_pymnt, total_rec_prncp, total_rec_int, total_rec_late_fee, recoveries

2. Create hierarchies:
   - Drag `sub_grade` onto `grade` to create Grade > Sub Grade
   - Right-click `issue_date` > Create > Custom Date > Year, then Quarter, then Month

3. Create calculated field: `Loans` = 1 (to use SUM([Loans]) for counting)

4. Hide unused raw fields if any

## Step 3: Build All Calculated Fields (IN THIS EXACT ORDER)

### 3.1 Flags (build these FIRST)
For each, right-click in Data pane > Create Calculated Field:

**Default Flag**
```
IF [loan_status] IN ("Charged Off","Default",
    "Does not meet the credit policy. Status:Charged Off") THEN 1 ELSE 0 END
```

**Mature Flag**
```
IF DATEADD('month',[term_months],[issue_date]) <= #2018-12-31# THEN 1 ELSE 0 END
```
> [!NOTE] 
> This depends ONLY on issue date and term, never on outcome. This prevents survivorship bias.

**Live Flag**
```
IF [loan_status] IN ("Current","In Grace Period",
    "Late (16-30 days)","Late (31-120 days)") THEN 1 ELSE 0 END
```

**Live Exposure**
```
IF [Live Flag]=1 THEN [out_prncp] ELSE 0 END
```

**Vintage**
```
DATETRUNC('quarter',[issue_date])
```

### 3.2 Core Risk Metrics

**Default Rate (Mature)**
```
SUM(IIF([Mature Flag]=1,[Default Flag],0)) / SUM(IIF([Mature Flag]=1,1,0))
```

**Net Loss $**
```
IF [Default Flag]=1 THEN [funded_amnt]-[total_rec_prncp]-[recoveries] ELSE 0 END
```

**PD by Grade (LOD)**
```
{ FIXED [grade] : SUM(IIF([Mature Flag]=1,[Default Flag],0)) / SUM(IIF([Mature Flag]=1,1,0)) }
```

**LGD (Portfolio, LOD)**
```
{ FIXED : 1 - SUM(IIF([Default Flag]=1,[recoveries],0)) /
              SUM(IIF([Default Flag]=1,[funded_amnt]-[total_rec_prncp],0)) }
```

**Row EL**
```
[Live Exposure] * [PD by Grade (LOD)] * [LGD (Portfolio, LOD)]
```

**Expected Loss $**
```
SUM([Row EL])
```

**EL Rate**
```
SUM([Row EL]) / SUM([Live Exposure])
```

### 3.3 Pricing Adequacy

**Weighted Coupon**
```
SUM([int_rate]*[funded_amnt]) / SUM([funded_amnt]) / 100
```

**Annualised Loss Rate**
```
SUM([Net Loss $]) / SUM([funded_amnt]*[term_months]/12)
```
> [!IMPORTANT] 
> Filter to Mature Flag=1 when using this.

**Pricing Cushion**
```
[Weighted Coupon] - [Annualised Loss Rate]
```

### 3.4 Stress Testing
First create TWO parameters:
- **PD Multiplier**: Float, Range, Min=1.0, Max=3.0, Step=0.1, Default=1.0
- **LGD Add-on**: Float, Range, Min=0, Max=0.20, Step=0.01, Default=0

**Row Stressed EL**
```
[Live Exposure] * MIN(1,[PD by Grade (LOD)]*[PD Multiplier])
   * MIN(1,[LGD (Portfolio, LOD)]+[LGD Add-on])
```

**Stressed EL $**
```
SUM([Row Stressed EL])
```

**Stress Delta $**
```
[Stressed EL $] - [Expected Loss $]
```

### 3.5 Bands & Concentration

**FICO Band**
```
IF [fico]<660 THEN "<660" ELSEIF [fico]<700 THEN "660-699"
ELSEIF [fico]<740 THEN "700-739" ELSE "740+" END
```

**DTI Band**
```
IF [dti]<10 THEN "<10" ELSEIF [dti]<20 THEN "10-19" ELSEIF [dti]<30 THEN "20-29" ELSE "30+" END
```

**Delinquency Bucket**
```
CASE [loan_status]
WHEN "In Grace Period" THEN "Grace"
WHEN "Late (16-30 days)" THEN "16-30"
WHEN "Late (31-120 days)" THEN "31-120"
END
```

**State Share** (TABLE CALC — create on a sheet, not standalone)
```
SUM([funded_amnt]) / TOTAL(SUM([funded_amnt]))
```
Address computation using: State

**HHI** (TABLE CALC)
```
WINDOW_SUM(([State Share])^2)
```

**Cum % (Pareto)** (TABLE CALC)
```
RUNNING_SUM(SUM([funded_amnt])) / TOTAL(SUM([funded_amnt]))
```
Sort descending by funded_amnt.

**QoQ %** (TABLE CALC)
```
(SUM([funded_amnt]) - LOOKUP(SUM([funded_amnt]),-1)) / ABS(LOOKUP(SUM([funded_amnt]),-1))
```

Also create a parameter:
- **View By**: String, List, values: "Grade", "Purpose", "State"

- **Metric Selector**: String, List, values: "Funded $", "EL Rate"

Move calculated fields into these folders:
- **Flags**: Default Flag, Mature Flag, Live Flag, Live Exposure, Vintage
- **KPIs**: Default Rate (Mature), Net Loss $, PD by Grade (LOD), LGD (Portfolio, LOD), Row EL, Expected Loss $, EL Rate
- **Pricing**: Weighted Coupon, Annualised Loss Rate, Pricing Cushion
- **Stress**: PD Multiplier param, LGD Add-on param, Row Stressed EL, Stressed EL $, Stress Delta $
- **Bands**: FICO Band, DTI Band, Delinquency Bucket
- **Concentration**: State Share, HHI, Cum % (Pareto), QoQ %

## Step 4: Build Dashboard Sheets

### Dashboard 1: Executive Control Tower (D1)
Fixed size: 1400 × 900

**Sheet: KPI Strip** (make 7 separate sheets, one per KPI)
- KPI 1: Create sheet. Drag SUM(funded_amnt) to Text. Format as currency abbreviated. Title = "Total Funded"
- KPI 2: SUM(Loans) to Text. Format as number abbreviated. Title = "Total Loans"
- KPI 3: Default Rate (Mature) to Text. Format as percentage 2 decimal. Title = "Default Rate (Mature)"
- KPI 4: SUM(Live Exposure) to Text. Format as currency abbreviated. Title = "Live Exposure"
- KPI 5: Expected Loss $ to Text. Format as currency abbreviated. Title = "Expected Loss"
- KPI 6: EL Rate to Text. Format as percentage 2 decimal. Title = "EL Rate"
- KPI 7: Pricing Cushion to Text. Format as percentage 2 decimal. Title = "Pricing Cushion"

For each: remove grid lines, row/column dividers. Set background to white. Use a large font (20pt+) for the value, small grey font (10pt) for the title.

**Sheet: Quarterly Issuance (Dual Axis)**
- Columns: QUARTER(issue_date)
- Rows: SUM(funded_amnt) — change to Bar, colour = accent blue
- Add Default Rate (Mature) to Rows — change to Line, colour = red
- Right-click the right axis > Synchronize Axis (only if scale makes sense; otherwise just Dual Axis)
- Add labels to the line
- Format: remove gridlines, add axis titles

**Sheet: Breakdown by Grade** (will be toggled)
- Rows: grade (sorted A→G)
- Columns: SUM(funded_amnt)
- Colour: Default Rate (Mature)
- Labels: SUM(funded_amnt), Default Rate (Mature)

**Sheet: Breakdown by Purpose** (toggled)
- Same structure but with purpose on Rows

**Sheet: Breakdown by State** (toggled)
- Same structure but with addr_state on Rows, sorted desc by funded_amnt

**Dashboard Assembly:**
1. New Dashboard > Fixed Size 1400 × 900
2. Drag 7 KPI sheets into a horizontal container at the top
3. Add the quarterly issuance chart below
4. Create a parameter: "View By" (String list: Grade, Purpose, State)
5. Use Dynamic Zone Visibility:
   - Add all 3 breakdown sheets to a vertical container
   - For each, set visibility condition based on the View By parameter value
6. Show Parameter Control for "View By"
7. Add Navigation buttons (Dashboard > Objects > Navigation) to D2, D3, D4, D5, D6
8. Create a Phone layout: Layout > Phone > rearrange KPIs vertically, keep quarterly chart, skip breakdown

### Dashboard 5: Stress Test & Delinquency Watchlist (D5)

**Sheet: Waterfall (Gantt-bar method)**
This is the trickiest chart. Steps:
1. Create a calculated field "Waterfall Category" with values: 'Base EL', 'PD Stress', 'LGD Stress', 'Stressed EL'
2. Create measures for each segment:
   - Base EL = Expected Loss $
   - PD Stress Effect = (Stressed EL at current PD Multiplier with LGD Add-on=0) - Base EL
   - LGD Stress Effect = Stress Delta $ - PD Stress Effect
   - Stressed EL = Stressed EL $
3. Use Gantt bar mark type:
   - Columns: Waterfall Category (sorted manually)
   - Rows: Running total of previous segments (starting point)
   - Size: Segment value (negative for the running bar)
4. Colour: green for Base, red shades for stress effects, dark red for total

Alternative simpler approach: Create a stacked bar showing Base EL, PD Stress Effect, LGD Stress Effect.

**Sheet: Stress Line vs Coupon**
- Create a sheet that shows: for PD Multiplier values 1.0 to 3.0, what is the Stressed EL Rate?
- Overlay Weighted Coupon as a horizontal reference line
- This shows at what multiplier the cushion goes to zero
- (This may require a scaffold data source or manual calculation; describe the approach)

**Sheet: Delinquency Watchlist**
- Rows: Delinquency Bucket
- Columns: grade
- Colour: SUM(Live Exposure)
- Filter: Live Flag = 1, Delinquency Bucket is not Null
- This is a highlight table

**Sheet: Top 20 Delinquent Cells**
- Rows: sub_grade, addr_state
- Columns: SUM(Live Exposure) where Delinquency Bucket is not null
- Sort desc, use RANK table calc or just top N filter
- Show top 20 only

Show Parameter Controls for PD Multiplier and LGD Add-on.

**Dashboard Assembly:**
- Top: parameter controls
- Left: Waterfall chart
- Right top: Stress line
- Bottom left: Delinquency heatmap
- Bottom right: Top 20 watchlist
- Navigation back to D1

## Step 5: Formatting & Polish
1. **Colour Palette**: Use ONE accent colour consistently. Grade colours A→G should be ordinal (light blue to dark red or similar).
2. **Tooltips**: Customise every tooltip with clear labels, formatting, and context.
3. **Titles**: Every sheet/dashboard should have a clear title.
4. **Remove clutter**: Hide field labels for rows/columns, remove gridlines, simplify.
5. **Test all interactions**: Every parameter, filter, action, and navigation button.
6. **Performance**: Help > Settings and Performance > Start Performance Recording. Fix any sheet over 3 seconds.
